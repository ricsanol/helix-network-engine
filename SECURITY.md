# Security

This public portfolio version contains only fictitious lab data.

- Do not commit `.env`, credentials, production exports, logs, reports, or generated configurations.
- Use environment variables for SSH credentials.
- The sample spreadsheets use documentation-only address ranges and fictitious hostnames.
- Review `git status` and `git diff --staged` before every public commit.

If adapting this project to a real network, keep operational inventory and secrets outside the repository.
